# Course Local Reader

用于把用户**已拥有访问权限**的在线课程内容整理为本地资料，并生成可阅读的静态页面。

## 触发条件

当用户出现以下意图时应触发：

- 抓取课程原文 / 导出课程内容
- 保存课程为 Markdown
- 生成本地阅读站 / 双语对照阅读页
- 整理课程目录树 / 阅读顺序
- 通过已登录浏览器读取 Skilljar 或类似学习平台课程

## 边界

- 只处理用户**已登录且有权访问**的课程页面
- 默认输出为**本地使用**产物
- 如果用户要公开部署、推送 GitHub 或外部分享，必须提醒版权与平台条款风险
- 不绕过登录、权限、验证码或站点限制

## 执行流程

### 1. 确认可访问页面

- 优先使用浏览器插件或已登录浏览器上下文
- 先验证课程页是否可见，再读取课程目录和课时链接
- 如果某一页无法访问，明确标记缺失，不要伪造内容

### 2. 抽取课程结构

至少整理出：

- 课程标题
- 模块/分组标题
- 课时标题
- 课时 URL
- 课时顺序

默认阅读顺序：按课程目录树从上到下。

### 3. 抓取正文

对每个课时：

- 提取标题、时长、段落、列表、表格、可见链接
- 视频或嵌入内容统一标记为 `[Embedded content]`
- 对纯前端异步页，允许先访问页面再读 DOM，而不是仅靠静态 HTML

### 4. 落盘规则

默认目录结构：

```text
course-folder/
  lesson-slug.md
  lesson-slug-zh-CN/
    translation.md
  reader.html
```

规则：

- 英文原文文件使用 kebab-case 文件名
- 中文翻译放到 `lesson-slug-zh-CN/translation.md`
- Markdown 标题使用课程名作为一级标题，课时名作为二级标题

### 5. 生成阅读站

阅读站至少要支持：

- 左侧课程目录树
- 固定阅读顺序
- 上一课 / 下一课
- 原文链接
- 英文、中文、双语对照切换
- 本地静态打开或通过 localhost 访问

如果页面较长，优先保证可读性，而不是做复杂交互。

### 6. 验证

至少验证：

- 目录树可切换课时
- 阅读顺序正确
- 原文链接跳转正确
- 中英切换正常
- 侧边栏、基本导航、表格渲染正常

## 输出要求

向用户汇报时应说明：

- 哪些课时已抓取
- 哪些页面内容缺失或只拿到加载态
- 本地阅读页路径或 localhost 地址
- 如果涉及课程原文/翻译，提示其仅作本地使用更稳妥

## 版权提醒

如果用户问“能否 push 到 GitHub / 上线网站”，必须明确：

- 代码与阅读器框架通常问题较小
- 课程原文、整段翻译、结构化整理内容存在明显版权和条款风险
- 没有书面授权时，优先建议仅本地使用
